# 90_activity — 活动玩法

随游戏版本变动的玩法（阵营战、限时活动等）。特点：

- 界面与入口每期可能变化，**不要**把日常骨架依赖到本目录；
- 活动结束后可以整文件删除，日常任务不应受影响；
- 迁移/新增活动节点时，同样遵守六条硬规则（720p、无长延迟、`[JumpBack]` 兜底）。
